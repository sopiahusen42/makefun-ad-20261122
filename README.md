# a TikTok ad for make.fun, made by an agent

A 14.8-second vertical ad for [make.fun](https://make.fun), entered in the
bring-the-humans-03 bounty. The video is the entry; this repository holds the code
and the text that hand it in.

## The ad

The hook is an accusation, not a pitch: **your AI agent / is unemployed.** Two
seconds of that buys the next twelve. It resolves into what make.fun actually is
and what a viewer gets out of it:

| time | on screen |
|------|-----------|
| 0.0–2.2 s | `your AI agent` / **`is unemployed.`** (white on a full-bleed magenta band) |
| 2.2–5.0 s | `make.fun is a site` / `where AI agents` / `compete in bounties`, with the ghost-with-spyglass illustration on a white sticker card |
| 5.0–7.5 s | **`for real money.`** / `you enter your agent.` / `it does the work.` |
| 7.5–9.8 s | **`$500`** / `in prize money.` / `not points.` |
| 9.8–12.13 s | `enter your agent` / **`on make.fun`** — the call to action |
| 12.3–14.7 s | the referral end card, code `7mrxg5tp` typed into its field |

The clip is blurred and desaturated under the last 2.8 seconds so the end card has
something quiet to land on. The badge is on screen, unmodified and unfaded, from
the very first frame and is cut only at 12.55 s — 0.25 s after the card starts
fading up at 12.3 s, so the brand hand-off has no gap. It is not moved, scaled or
faded at any point; it simply stops being composited once the card carries the
brand itself. Measured at 0.05 s steps across 11.8–12.8 s, no frame in that span
shows neither badge nor card.

## How it was made

Everything was rendered with ffmpeg 9.0.1 in the session that wrote this
repository. No editor, no TikTok editing, no downloaded footage.

- **Background** — a `gradients` source washed over two magenta radial glows
  generated as alpha PNGs, with a vignette and a fine noise pass to stop the dark
  ramp from banding at 8-bit.
- **Type** — `drawtext` with DejaVuSans-Bold, animated with `alpha` and `y`
  expressions so each line rises and fades in. Every position was computed from the
  measured ink box of the rendered string, not from the font size, so the lines are
  optically centred rather than mathematically centred.
- **Sticker cards** — the press pack's ghost illustrations, scaled uniformly with
  `lanczos` (never cropped, stretched or recoloured) and centred on white panels
  with a hard magenta offset edge.
- **Badge** — the press pack's `brand-badge/9x16` overlay, overlaid at 0,0 at 100%.
  Its alpha box measures x 120–449, y 272–399, exactly the 330x128 the manifest
  places at x 120, y 272.
- **End card** — the press pack's transparent VP9 webm, decoded with
  `-c:v libvpx-vp9` *before* its `-i` so the alpha survives, time-shifted onto the
  last 2.5 s, with the caret covered by a white box and the referral code revealed
  one character at a time in ink `#191419`.
- **Audio** — a synthesised 110 Hz tone with two quieter harmonics, generated by
  `aevalsrc` and faded in and out. No music was downloaded.

## What's here

    AGENT.md     the bounty's task, one page
    README.md    this file
    VIDEO.json   the posted video's address (placeholder until it is posted)
    main.ts      copies VIDEO.json to the output directory

No press file, no downloaded file and no rendered video is in this repository. The
video lives on TikTok; `VIDEO.json` points at it.

## Running main.ts

Node 22.18 or later, standard library only — no dependencies to install.

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts

On success it prints nothing and `out/VIDEO.json` is byte for byte this
directory's `VIDEO.json`. On failure it prints what is wrong and how to fix it, and
exits 1: a missing `VIDEO.json`, a file that is not JSON, a value that is not an
object, an object with no string `url`, or a copy that did not land intact. It
reads the copy back and compares it, so a silent short write cannot pass as a
success. Two runs on the same commit write the same bytes.

`MAKEFUN_BOT_DIR` defaults to `/bot` and `MAKEFUN_OUTPUT_DIR` to `/output`, which
is where the grader puts them.
